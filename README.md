# MyNavigate

从 ConsolePortLK 抽离出来的独立 UI 导航插件：用**手柄方向键**在暴雪/插件窗口中移动光标，
用 **ABXY** 执行控件动作（点击 / 右键 / 特殊点击 / 输入）。

- 不依赖 ConsolePort 的手柄驱动栈，只用 WoW 原生按键绑定
- 适用于 WLK 3.3.5（`Interface: 30300`）
- 配合安卓手柄控制器（发送 1~8 键）在 Winlator 里控制乌龟服 / WLK

## 安装

把 `MyNavigate` 整个文件夹放到：

```
Interface\AddOns\MyNavigate\
```

进入游戏后在插件列表里勾选加载，或 `/reload`。

## 按键映射

默认映射如下（**每个键都可以在设置面板里改**）：

| 按键 | 功能                                          |
| ---- | --------------------------------------------- |
| 5    | 上                                            |
| 6    | 下                                            |
| 7    | 左                                            |
| 8    | 右                                            |
| 1 / X| 左键点击                                      |
| 2 / B| 右键点击（背包里为「菜单」）                  |
| 3 / Y| 特殊（`SpecialClick` / 输入框聚焦 / 兜底左键）|
| 4 / A| 左键点击                                      |

按键通过**覆盖绑定**动态接管：只有当屏幕上存在可导航节点时才生效，
窗口全关后自动还原到各自的原始绑定，不写存档、不污染按键设置。
方向键绑成 `SetOverrideBinding`（自己处理移动），动作键（ABXY）在有名字的节点上绑成
`SetOverrideBindingClick`——把点击交回暴雪安全框架执行，这样背包里的「使用 / 拾取」
等受保护操作（`UseContainerItem`）才不会因插件直接调用而被拦下；无名节点或输入框
才退回 Lua 处理。

## 使用

1. 打开一个窗口（背包、角色、任务、商店等）
2. 屏幕上出现金色高亮框（动作提示框默认关闭，可在设置面板里打开）
3. 用方向键移动光标，ABXY 执行动作

**一个窗口都不开时不会高亮任何东西**——常驻 HUD（动作条、小地图、单位框体等）不在白名单里。

- **弹窗 / 下拉独占**：屏幕上只要出现弹窗（`StaticPopup`）或下拉菜单（`DropDownList`），
  导航范围就限定在它们里面，忽略背后的窗口；可在设置面板里关闭。
- **记忆回溯**：从窗口 A 进入窗口 B（或弹窗）后，B 一关掉，光标会回到 A 里原来的位置，
  而不是盲目跳到最近的节点。
- **打开窗口的自动落点**：窗口显示后约 50ms 就自动落点（见下方「工作原理」的事件驱动），
  按 `score = ny*10 - nx` 评分（越靠上、越靠左越高）取第二高分的节点，
  跳过最高分那个（通常是右上角的关闭按钮）。

## 设置面板

命令 `/mynav`（无参数）会打开 **界面 → 插件 → MyNavigate** 设置面板，可以开关：

| 选项            | 默认 | 说明                                         |
| --------------- | ---- | -------------------------------------------- |
| 启用导航        | 开   | 总开关，关闭后不再接管方向/动作键            |
| 弹窗 / 下拉独占 | 开   | 出现弹窗/下拉时只导航它们                    |
| 显示动作提示框  | 关   | 光标旁的提示框（tooltip 边框 + 小字号）      |
| 调试输出        | 关   | 在聊天框打印扫描到的面板与节点               |

**按键设置**：上 / 下 / 左 / 右 / A / B / X / Y 各有一个捕获按钮，点一下再按手柄物理键即可改绑
（默认就是上面的映射，按 ESC 取消），改完立即生效。

面板下方还能维护**自定义白名单**、**自定义黑名单**和**按钮黑名单**：填帧名或路径标识点「添加 / 移除 / 清空」（回车 = 添加）；
列表里的条目可以直接点选高亮，再点「删除选中」把它移除。窗口黑名单优先级高于白名单，
加入黑名单的窗口即使命中内置白名单也不会被导航；按钮黑名单里的控件在导航时会被直接跳过
（例如某个不叫 `close` 的关闭按钮）。

## 命令

| 命令                          | 说明                                                     |
| ----------------------------- | -------------------------------------------------------- |
| `/mynav` 或 `/mynav config`   | 打开图形设置面板                                         |
| `/mynav on` / `off`           | 开启 / 关闭插件（关闭会解绑，原始绑定仍保留）            |
| `/mynav reset`                | 恢复插件接管前的原始按键绑定                             |
| `/mynav debug`                | 开关调试输出                                             |
| `/mynav dump [关键词]`        | 列出顶层帧（无关键词时只列屏幕上可见的），标注是否可导航 |
| `/mynav pick`                 | **鼠标选取**：点一下要加入导航的窗口，自动加入白名单     |
| `/mynav unpick`               | **鼠标选取（黑名单）**：点一下要排除导航的窗口，自动加入黑名单 |
| `/mynav skip` / `skip <标识>` | 无参数时**鼠标选取**要跳过的控件；带标识时手动加入按钮黑名单 |
| `/mynav unskip <标识>`        | 移出按钮黑名单                                           |
| `/mynav add` / `remove <帧名>`| 手动增删白名单                                           |
| `/mynav block` / `unblock <帧名>`| 手动增删黑名单（优先级高于白名单）                  |
| `/mynav nodes`                | 打印当前扫描到的节点（名字 / 类型 / 可见 / 可绘制 / 坐标）|
| `/mynav tree <帧名>`          | 打印某个帧的子帧树                                       |

## 白名单 / 黑名单机制

导航根节点只从「白名单窗口」里取，名单由两部分组成：

1. **内置模式**：`Core.lua` 里的 `PANEL_PATTERNS`（背包、角色、任务、商店、邮件、地图、设置、弹窗……）
2. **用户自定义**：`MyNavigateDB.extra`，通过 `/mynav pick` 或 `/mynav add` 添加，保存在存档里

黑名单存在 `MyNavigateDB.black`，通过 `/mynav unpick`、`/mynav block` 或设置面板添加。
**黑名单优先级最高**：名字一旦在黑名单里，即使命中内置模式或自定义白名单也不会被导航。

按钮黑名单存在 `MyNavigateDB.nodeBlack`，记录窗口内部控件的标识，通过 `/mynav skip`
（无参数时鼠标选取）、`/mynav skip <标识>` 或设置面板添加。扫描时这些控件不会成为导航节点，
但仍会继续遍历它们的子帧，避免误伤容器里的其它按钮。

标识规则：有名字的控件直接用帧名；**无名控件**用「最近命名祖先 + 子帧索引路径」，例如
`@ImmersionFrame/3/2`。鼠标选取时会自动生成这种路径，也可以用 `/mynav nodes` 打印出来复制。
路径依赖插件的子帧创建顺序，同一插件每次登录一致，因此可以跨 `/reload` 保存。

这样既覆盖常见窗口，又能把你自己的插件面板一键接进来，同时避免把常驻 HUD 当成导航目标。

当「弹窗 / 下拉独占」开启时，只要 `StaticPopup1~4` 或 `DropDownList1~3` 可见，
上面的名单就临时失效，导航范围只限定在这些弹窗/下拉里。

## 工作原理

- **窗口开关 → 落点（事件驱动）**：`Core.lua` 给每个白名单根帧挂 `OnShow` / `OnHide` 钩子，
  窗口一显示/一隐藏就记下来，并在 50ms 的合并缓冲后刷新一次：
  - 同时开/关多个窗口（背包+银行、连关几个弹窗）只算一次刷新；
  - 这 50ms 也刚好等窗口把内部控件建好、重排完，避免落到半成品布局上；
  - 缓冲期里玩家自己按过方向键就放弃这次自动落点，不会和玩家抢光标。
- 只有晚创建 / 按需加载（`LoadAddOn`）的白名单窗口才靠 0.5s 的兜底轮询发现并补挂钩子，
  窗口开关本身不再等轮询。
- **增量重扫**：缓存按根窗口打标。只有变化的窗口被剔除并重扫，其余窗口沿用上次缓存；
  有窗口关闭（或被弹窗独占挤掉）时退回全量扫描，因为关掉的窗口之前在遮挡剔除里
  删掉过别的窗口的节点，只扫新窗口捞不回来。
- `Node.lua` 用显式栈迭代扫描根窗口下的所有子帧（不递归，宽窗口不会把 Lua 栈顶爆）：
  - 可交互控件（Button / CheckButton / EditBox / Slider，或带 `OnEnter` / `OnMouseDown` 的 frame）→ 导航节点
  - 其它可见 frame → 遮挡矩形
- 扫描结束后剔除被遮挡矩形盖住的节点
- 选目标时：先按方向过滤（上下要求纵向距离大于横向，左右反之），再按「轴向拉伸后的距离」取最优；
  若找不到合适的，退化为「同方向上最近的节点」
- `Cursor.lua` 负责把金色高亮框画到当前节点外沿、用提示框显示动作提示，并执行点击；
  跨窗口切换时用记忆栈记下原来的位置，窗口关掉后回溯过去

## 文件结构

```
MyNavigate.toc   插件清单（加载顺序 / SavedVariables）
Bindings.xml     按键绑定声明（MYNAV_UP/DOWN/LEFT/RIGHT/A/B/X/Y）
Node.lua         节点扫描 + 方向选择算法（核心，移植自 ConsolePort）
Cursor.lua       虚拟光标：高亮框、提示框、记忆回溯、动作执行
Core.lua         入口：按键绑定、窗口白名单、刷新、斜杠命令
Options.lua      图形设置面板（/mynav 打开）
```

## 已知限制

- **按键设置（`KeyBindingFrame`）窗口无法用按键导航**：该窗口会吞掉键盘输入
  （按设计如此，它本来就是用来录按键的），所以在这个窗口里方向键不会触发插件。
- 长列表（按键设置、任务列表等）只有**当前可见的行**在导航范围内。

## 调试

`/mynav debug` 打开后，每次刷新会打印一行：

```
MyNavigate 面板 3 节点 46 当前 AchievementFrameCategoriesContainerButton5
```

若某个窗口不响应：用 `/mynav dump` 看它在不在白名单，或用 `/mynav pick` 加进去。
